# 悬浮备忘录

想到什么，随手记——不用切回桌面，也不用专门打开 App。

👉 **[去下载最新版](https://github.com/ydxbnn/mimi/releases)**

---

## 一、它能做什么

- **在任何 App 里随手记**：看网页、刷视频、聊天的时候，点一下屏幕边缘的紫色气泡，弹出一个小输入框，写完点「快速保存」，气泡自动缩回去，不打断你正在做的事。
- **记完不丢**：内容存在手机本地，关掉 App、下次再打开都还在。
- **一个列表看全部**：打开 App 就能看到所有备忘，按时间排好；每条都能一键复制或删除。
- **气泡可以挪位置**：觉得挡视线，按住拖到别处就行，下次还在那儿。
- **浅色深色都舒服**：支持浅色、深色、跟随系统。

---

## 二、怎么安装和使用

### 安装

1. 打开 **[Releases 页面](https://github.com/ydxbnn/mimi/releases)**。
2. 下载最新的 **2.0 版本**：`floating-memo-v2.0.0.apk`。
3. 点开安装。如果提示「未知来源」，允许安装即可。

> 如果装 2.0 后手机出现闪退，多半是系统版本偏旧，换 **1.0 基础版** `floating-memo-v1.0.0.apk` 就好。

### 第一次使用

1. 打开 App，点顶部的「悬浮窗」开关。
2. 手机会跳到权限页，找到「**显示在其他应用上层**」并打开（不同手机叫法不一样，见第四部分）。
3. 回到 App，屏幕边缘就会出现紫色气泡。
4. 点气泡 → 弹出输入框 → 打字 → 点「快速保存」。
5. **长按气泡约半秒**，它会缩小消失；App 里的开关也会自动变成关闭。

## 三、它的限制（为什么有时会消失）

这个气泡是「借」安卓系统的一层显示能力，不是系统自带的功能，所以有几条硬限制：

- **把 App 从后台彻底划掉，气泡会消失。**
  这是安卓的安全设定：App 被彻底关掉，它画在屏幕上的东西也会一起收走。我们加了前台服务尽量让它活得久（通知栏会有一条「悬浮备忘录运行中」），但如果你手动「强行停止」或划掉它，气泡还是会没。
- **不支持像系统那样「拖进垃圾桶」关闭。**
  那种交互要系统级权限，普通 App 拿不到。所以我们改用**长按气泡**来关，效果一样，只是手势不同。
- **手机重启后不会自动出现。**
  需要重新打开 App、再开一次悬浮窗开关。
- **有些手机还需要额外「放行」。**
  比如允许后台运行、允许自启动，否则系统可能更早把气泡收掉。

## 四、可能存在的 Bug

老实说，这类悬浮窗在不同手机上差别挺大，已知的情况有：

- **权限名字不统一**：小米、OPPO、vivo 等品牌里，这项权限可能叫「悬浮窗」「显示悬浮窗」「在其他应用上层显示」等，找带「悬浮」或「上层」字样的那一项就行。
- **深色模式切换有延迟**：切浅色/深色时，输入框可能晚一拍变色，重新点开一次即可。
- **锁屏解锁后气泡位置可能偏一点**：个别机型会这样，拖一下就好。
- **通知栏可能看不到那条常驻通知**：安卓 13 及以上如果拒绝了通知权限，前台服务仍在跑，只是通知不显示。
- **省电策略可能提前收掉气泡**：如果经常消失，去系统设置里把本 App 加进「后台运行 / 自启动 / 电池不优化」白名单。

遇到上面之外的问题，欢迎到 **[Issues](https://github.com/ydxbnn/mimi/issues)** 反馈，尽量带上手机型号和系统版本。

## 给想动手改代码的人

项目用 React Native + Expo 开发；悬浮气泡是 Android 原生代码，所以要打开发包，不能直接用 Expo Go 跑：

```bash
npm install
npx expo run:android                        # 需要本机有 Android 开发环境
# 或云端打包
npx eas-cli build --platform android --profile preview
```

代码位置：`App.tsx`（主界面）、`src/`（界面与本地存储）、`modules/floating-memo/`（悬浮气泡原生部分）。
